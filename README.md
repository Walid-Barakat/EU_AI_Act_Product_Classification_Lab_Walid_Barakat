## Repository purpose

This repository contains only the materials prepared for **LAB | Classify your product**. It applies the EU AI Act risk framework to four client scenarios and documents the classifications, role assignments, recommended controls, and consulting decisions.

No unrelated projects, personal files, raw workspace dumps, credentials, environment files, or cloud-only documents belong in this repository.

| Case | First-pass classification | Consulting decision |

| 1. Workforce engagement analyser | Prohibited workplace emotion recognition | Deny and redesign |
| 2. Grid congestion and switching system | High-risk critical-infrastructure AI | Approve only with high-risk controls and human authorisation |
| 3. Energy-grant information chatbot | Transparency or limited risk | Approve with Article 50 disclosure, bounded retrieval, and human escalation |
| 4. Solar-panel cleaning optimiser | Minimal risk | Approve with proportionate governance and change control |

## GitHub submission procedure

1. Sign in to GitHub and create a new repository named `eu-ai-act-product-classification-lab`.
2. Select the visibility required by the course. If the instructor must access a private repository, add the instructor as a collaborator before submission.
3. Upload only the three files listed in the file map. Upload the contents of this package, not the enclosing ZIP file.
4. Use the commit message: `Submit EU AI Act product classification lab`.
5. Open the published repository and test both Markdown links in the file map.
6. Confirm that the solution tables, headings, lists, and source links render correctly on GitHub.
7. Copy the repository URL from the browser address bar and submit that URL through the course channel.
